# 1Ecomm Flutter Storefront Starter

Flutter iOS/Android/web reference storefront for the 1Ecomm public catalog preview. Synthetic fixtures are the default; configure approved sandbox values with `--dart-define` only after live keys exist.

Run `flutter analyze`, `flutter test`, `flutter build web`, then `npm install && npm run test:e2e` for the compiled-web Playwright journey. Native signing, PKCE, secure storage, deep links and checkout return handling remain release gates.
